### 3. Exposure, Alternatives, and Remaining Risk for Unresolved Build-Time Findings

- **Actual exposure:**
  - Neither `tailwindcss`, `chokidar`, `micromatch`, `fast-glob`, `braces`, `postcss-nested`, nor `postcss-selector-parser` is included in the compiled frontend bundle (`frontend/dist/`) or executed in the browser or Nginx runtime container.
  - `GHSA-vfj7-8cjw-p6xm` (`braces <=3.0.3`) is a stack-exhaustion DoS triggered only when deeply nested brace patterns are passed to glob matching (`tailwind.config.js` `content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"]` is static and repository-controlled).
  - `GHSA-rj75-hqrm-r3gf` (`postcss-selector-parser <7.1.6`) is quadratic CPU time when parsing crafted flat CSS selectors at build time (all CSS/Tailwind classes in MedVault are authored in-repo; no user-supplied CSS is compiled).
- **Available alternatives:**
  1. **Migrate from Tailwind CSS v3 (`3.4.19`) to Tailwind CSS v4 (`4.3.3`):** eliminates the `chokidar@3`/`micromatch`/`braces` and `postcss-nested`/`postcss-selector-parser@6` dependency subtree completely, but is a **breaking SemVer major upgrade** (`isSemVerMajor: true`) requiring a dedicated migration of `tailwind.config.js`, `postcss.config.js`, and `@tailwind` directives in `src/index.css`. Per authorization constraints, `npm audit fix --force` and unreviewed major upgrades were not applied.
  2. **Lockfile `overrides`:** `braces` has no patched `3.x` version (`*` / `<=3.0.3` is vulnerable), so an override cannot remediate `GHSA-vfj7-8cjw-p6xm`. Overriding `postcss-selector-parser` to `^7.1.6` forces a major version bump across `tailwindcss@3.4.19` and `postcss-nested@6.2.0` (`^6.0.11`) without upstream verification.
- **Remaining risk & release disposition (D7, decided 2026-10-10):**
  - **Runtime / production bundle risk:** **None** from the 7 remaining entries (`npm audit --omit=dev` = `0 vulnerabilities`; all production runtime advisories in `axios` and `react-router`/`react-router-dom` are patched).
  - **Build / CI environment risk:** **Low** (build-time DoS only if untrusted CSS or glob configurations are introduced into the repository). A successful `npm run build` does **not** prove all dependencies in `node_modules` are vulnerability-free; the 7 dev/build-time findings remain open in `npm audit`. Per user decision D7 (2026-10-10), these 7 build-only advisories are **accepted for this release** and the breaking Tailwind CSS v4 migration is **deferred to a future phase**.
